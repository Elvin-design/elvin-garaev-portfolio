# Портфолио Elvin Garaev

Сайт сделан на обычных HTML, CSS и JavaScript. Сборка ему не нужна: Vercel показывает файлы как есть, поэтому ломаться при выкладке нечему.

Адрес сайта: https://elvin-garaev-portfolio.vercel.app

## Что где лежит

| Файл или папка | Что внутри |
|---|---|
| `index.html` | главная: заголовок, карточки кейсов, опыт, контакты и текст About |
| `work/` | страницы кейсов: `ukrsibbank`, `ifreq`, `xgo`, `p3-wealth`, `p3-marine`, `safe`, `cryptoswift` |
| `styles.css` | общее оформление: сайдбар, темы, главная. Цвета светлой и тёмной темы собраны в начале файла |
| `case.css` | оформление страниц кейсов и всех живых макетов внутри них |
| `script.js` | сайдбар, меню на телефоне, тема, окно About, переходы между страницами |
| `case.js`, `live.js` | анимации появления блоков и интерактивные макеты в кейсах |
| `images/` | все картинки: `cases` — экраны кейсов, `logos` — логотипы, `icons` — иконки компаний в сайдбаре, `elvin` — фото |
| `og-image.jpg` | картинка, которая показывается, когда ссылку присылают в LinkedIn или Telegram |
| `favicon.ico`, `icon.png`, `apple-touch-icon.png` | иконка сайта во вкладке браузера и на телефоне |
| `404.html` | страница «такой страницы нет» |
| `vercel.json` | настройка Vercel: адреса без `.html` на конце, например `/work/safe` |
| `sitemap.xml`, `robots.txt` | подсказки для поисковиков |

## Как выложить сайт

1. На github.com создай репозиторий `elvin-garaev-portfolio`.
2. Загрузи в него всё содержимое этой папки: сами файлы и папки, а не папку целиком. Через сайт GitHub за один раз можно загрузить не больше 100 файлов, поэтому загружай в два захода: сначала всё, кроме папки `images`, потом папку `images`.
3. На vercel.com нажми **Add New… → Project**, выбери репозиторий `elvin-garaev-portfolio` и нажми **Import**.
4. В поле **Framework Preset** выбери **Other**, остальное не трогай и нажми **Deploy**.
5. Через минуту сайт откроется по адресу https://elvin-garaev-portfolio.vercel.app. Старый сайт на elvin-garaev.vercel.app продолжит работать как раньше.

Если Vercel даст другой адрес, замени `elvin-garaev-portfolio.vercel.app` на новый в файлах `index.html`, `work/*.html`, `sitemap.xml` и `robots.txt`. Иначе превью ссылки в соцсетях будет брать картинку по старому адресу.

## Как поменять текст

1. Открой нужный файл на GitHub (`index.html` или страницу в `work/`) и нажми на карандаш (**Edit this file**).
2. Найди текст через Cmd+F и поправь его.
3. Нажми **Commit changes**. Через минуту сайт обновится сам.

Меняй только текст между тегами, то, что внутри `< >`, не трогай. В коде `&amp;` означает знак `&`.

## Как поменять картинку

Загрузи новый файл с **тем же именем** в ту же папку (**Add file → Upload files**), и он заменит старый.

## Как устроены темы

Если посетитель сам не выбирал тему, сайт берёт её из настроек системы и браузера: тёмная система — тёмный сайт, светлая — светлый. Выбор Light или Dark в сайдбаре запоминается.
